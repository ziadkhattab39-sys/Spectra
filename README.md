# ✦ SPECTRA
### See Beyond the Ordinary.

**SPECTRA** is a Smart Photo Organizer built with Python, designed to transform scattered photo collections into an organized, searchable, and visually accessible gallery.

Instead of manually browsing through countless folders to find a particular image, SPECTRA allows you to organize your photos using customizable tags and discover images through multiple-tag searches.

A personal photo library, reimagined.

---

## ✨ Features

- **Smart Photo Organization:** Bring together photos scattered across your computer into one organized environment.
- **Tag Management:** Create, manage, and assign custom tags to your photos.
- **Multi-Tag Search:** Find specific photos using multiple tags simultaneously.
- **Interactive Gallery:** Browse and explore your organized photo collection through a graphical interface.
- **Photo Management:** Import and manage your personal image collection.
- **Local Data Storage:** Keep your photo organization data locally.

## 🛠️ Built With

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- pip

### Installation

1. Clone the repository:

```bash
git clone https://github.com/ziadkhattab39-sys/Spectra.git
```

2. Navigate to the project directory:

```bash
cd SPECTRA
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application's main entry point.

## 🎨 Design Philosophy

SPECTRA's visual identity revolves around the idea of seeing things differently.

Its aesthetic combines deep, purple-tinted charcoal tones with royal violet accents, creating a minimal and elegant visual experience.

The project's identity also incorporates two symbolic elements:

- **The Prism:** Representing the project's name and the idea of discovering different perspectives.
- **The North Star:** Representing direction, discovery, and the pursuit of something beyond the ordinary.
